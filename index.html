토큰 만드는 방법
  1. github.com 로그인 → 오른쪽 위 프로필 사진 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token
  4. Token name: stock-app, Expiration: 1년(366 days)
  5. Repository access: Only select repositories → rave-stock-bot, rave-stock-data 선택
  6. Permissions → Repository permissions → Contents를 Read and write로
  7. 맨 아래 Generate token → 나온 값 복사해서 위 칸에 붙여넣기
